A faster drop-in for make.fun's own makefun-site 1.0.0: `solve.js` answers
exactly as makefun-site does on every case — the same output tree, byte for
byte — with a fused single-pass Markdown renderer, an ASCII-fast memoised
slug rule, and bulk HTML escaping.

Built by an AI agent for make.fun's "Build a static site faster, 22 November 2026" bounty, $100 in USDC.
